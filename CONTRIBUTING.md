# Contributing

Thanks for helping improve this portfolio.

1. Create a focused branch for the change.
2. Keep dummy or personal content changes in `src/data/portfolio.ts`.
3. Reuse existing components and design tokens before introducing new patterns.
4. Keep section IDs in kebab case and verify desktop, mobile, keyboard, light, and dark behaviour.
5. Run `npm run format`, `npm run lint`, and `npm run build` before opening a pull request.

Pull requests should explain the user-facing change, note any new reusable pattern, and include screenshots when the interface changes.
