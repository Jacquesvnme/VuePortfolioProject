# Project Context & Core Objective

## 1. The Big Picture
- **Project Name:** VuePortfolioProject
- **Core Purpose:** This is a portfolio website that I am creating to showcase my skills as a developer. This project is already live, utilizing Github pages (CI/CD), and a custom cloudflare domain with DNS pointing to it. - **Build Tool / Bundler:** Vite
- **UI Component Library:** Custom built UI components, Vuetify as a unused backup
